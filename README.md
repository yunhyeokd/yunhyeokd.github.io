# yunhyeokd.github.io

백엔드 개발자 도윤혁의 포트폴리오 사이트입니다.

**https://yunhyeokd.github.io**

## 구성

빌드 도구 없이 정적 HTML · CSS · JS로 만들었고, GitHub Pages로 배포합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 메인 페이지 — 소개, 프로젝트, 기술, 이력 |
| `investory.html`, `ieum.html`, `dozy-coffee.html` | 프로젝트 상세 페이지 |
| `header.js`, `footer.js` | 모든 페이지가 함께 쓰는 헤더 · 푸터 (`<site-header>`, `<site-footer>`) |
| `style.css` | 공통 스타일과 색상 토큰 |
| `detail.css` | 프로젝트 상세 페이지 전용 스타일 |
| `script.js` | 라이트 · 다크 테마 전환 |

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 별도 서버나 설치가 필요 없습니다.
