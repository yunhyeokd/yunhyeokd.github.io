소개

백엔드를 중심으로 서비스가 실제로 동작하기까지 필요한 전반을 고민하는 개발자입니다.
API 설계와 서버 구현뿐 아니라 도메인 구조와 아키텍처를 고민하고, Git 저장소 관리부터 Docker·GCP 기반 인프라와 CI/CD까지 직접 경험하며 서비스 전체의 흐름을 이해하려 노력해왔습니다. 필요한 문제라면 역할의 경계를 두지 않고 새로운 영역을 배우는 것도 좋아합니다.
최근에는 DDD, MSA, Hexagonal Architecture를 학습하며 더 나은 소프트웨어 구조를 고민하고 있습니다. 또한 MCP를 활용하여 AI 에이전트가 개발 과정의 컨텍스트를 효과적으로 활용하는 방법에도 관심을 두고 있습니다.
하나의 기능을 구현하는 데 그치지 않고, 문제와 서비스 전체를 이해하며 더 나은 해결 방법을 찾아가는 개발자가 되고자 합니다.
